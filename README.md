
# Calculadora Java y HTML

## Descripción
Proyecto de una aplicación web creada utilizando Java y HTML, cuya función es realizar diferentes operaciones matemáticas de forma sencilla. La calculadora permite efectuar cuatro tipos de operaciones: suma, resta, multiplicación y potencias.

## Operaciones disponibles
- Suma
- Resta
- Multiplicación
- Potencias

## Estructura de las ramas del proyecto
- **main:** Rama principal del proyecto, donde se integran los cambios realizados en las demás ramas.
- **frontend:** Rama destinada al desarrollo de la parte visual de la aplicación, incluyendo los archivos HTML.
- **backend:** Rama que contiene la parte lógica del programa y el código desarrollado en Java.

## Comandos utilizados

1. `git init` - Crear e inicializar el repositorio Git.
2. `git branch -M main` - Establecer el nombre de la rama principal como main.
3. `git add README.md` - Añadir el archivo README al control de versiones.
4. `git commit -m "Inicializar repositorio"` - Realizar el primer commit.
5. `git switch -c frontend` - Crear la rama frontend y cambiar a ella.
6. `git switch main` - Volver a la rama principal.
7. `git switch -c backend` - Crear la rama backend y acceder a ella.
8. `git branch` - Mostrar las ramas existentes en el repositorio.
9. `git switch frontend` - Cambiar a la rama frontend.
10. `git add index.html` - Añadir el archivo HTML al seguimiento de Git.
11. `git commit -m "Crear interfaz HTML de calculadora"` - Guardar los cambios de la interfaz.
12. `git switch backend` - Cambiar a la rama backend.
13. `git add CalculadoraServer.java` - Añadir el archivo Java al repositorio.
14. `git commit -m "Implementar operaciones matemáticas en Java"` - Guardar la implementación de las operaciones.
15. `git switch main` - Regresar a la rama principal.
16. `git merge frontend` - Integrar los cambios de la rama frontend en main.
17. `git merge backend` - Incorporar los cambios de la rama backend en main.
18. `git remote add origin URL` - Vincular el repositorio local con el repositorio remoto de GitHub.
19. `git push -u origin main` - Subir la rama principal a GitHub.
20. `git push -u origin frontend` - Publicar la rama frontend en GitHub.
21. `git push -u origin backend` - Publicar la rama backend en GitHub.
